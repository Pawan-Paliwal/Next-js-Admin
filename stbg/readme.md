# Affordplan Website
Official affordplan website built with Next.js 16.

---

## Requirements
- **Node.js** v20.x

---

## Installation
Install dependencies:

```bash
npm install
```

> **Note:** The `.env` file will be created automatically after running `npm install`.

---

## Running the Project
Start the development server:

```bash
npm run serve
```

The frontend will be served on **http://localhost:3010** and the backend will be on **http://localhost:3011**.

---

## Build
Build the project:

```bash
npm run build
```
